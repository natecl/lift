## Current product sentence

Lift teleports your active coding workspace to a persistent cloud computer so any coding agent can keep working after you close your laptop.

## Current narrow wedge

One user lifts one active coding project from macOS into an isolated persistent Linux workspace, continues Claude Code or Codex from a phone, views one protected development preview, and safely reconciles the result back to the laptop.
